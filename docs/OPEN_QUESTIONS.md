## How to record an answer

Replace "Not yet measured" with: date; node or browser and version; the exact command or request;
the raw output line that decides it; then one sentence of interpretation. Keep the log or screenshot
under `docs/measurements/` with the same date (the directory does not exist yet; the 2026-09-29 run
left no log file, only the panel text quoted above). A question answered "no" is recorded, not
deleted, with what was tried next.
